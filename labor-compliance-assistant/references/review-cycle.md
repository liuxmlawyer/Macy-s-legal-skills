# 复核与定稿

## 复审核验
- 用户提供书面意见时：按「编号/位置/意见/类型/修改/状态」处理表逐轮处理至定稿。
- 用户在文档中留有批注时：读取批注→定位→分类（直接改/检索后改/待专业确认/需澄清/核验无需改）→逐条回复。

## 边界
- 风险等级只在新事实/新依据/用户确认后调整。
- 要求补充依据时重新真实检索；判断性意见无法处理进入待专业人员确认。
- 不删除原结论除非用户要求；不自动向第三人发送报告。
- 个人知识库与公开库冲突时，以公开现行法为准，差异写入报告。

## 定稿
检查意见全处理、来源/时效/汇总与正文一致、记录定稿日期/确认人/未决事项。
