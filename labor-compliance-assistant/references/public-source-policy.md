# 来源分级 / 时效核验 / 检索纪律（防旧法闸门）

## 🔴 取源顺序铁律（最高优先级，不可颠倒）

法条法律验证的取源**权威性顺序**强制：

```
① 权威源法条原文（国家法律法规数据库 / 专业法律数据库，如北大法宝）
      ↓ 不可用 / 未收录
② 自建知识库 raw/00-法律法规/ 的法规原文
      ↓ 与①冲突
   以权威源为准，差异写入报告「待确认」区
```

**实际怎么取**，由本次任务开始时的**能力探测**决定，顺序为：
权威源 MCP → 专业法律库 MCP → **官方站点直取** → 限定官方域名的通用网络检索。

- **不可跳过权威源直接查知识库**
- **权威源与知识库冲突 → 以权威源为准**
- **权威源工具不可用时**：改用官方站点直取或通用网络检索（限定官方域名）取原文；
  仍取不到官方原文的，须在报告标注"未能使用权威源验证，仅使用知识库材料"，
  关键结论标【需专业人员确认】
- **严禁编造条文号、条文内容，或编造未发生的工具调用**
- ⚠️ 取法规时**必须先看"状态/时效"字段**——同名不同状态并存常见（已废止/生效中/被修订）

> 📌 **来源可信度 ≠ 工具可用性**：
> 通过官方站点直取取得的法条原文，与通过 MCP 取得的原文**具有同等权威性**，
> 不得因为"没接 MCP"就把官方直取降格写成"仅知识库"；
> 但确实未取到原文的，如实标"未核验"。
>
> 📌 **完整规则与调用范式见 `kb-search-protocol.md` 序章与第一节。**
> 本文件**不记录任何特定机器的环境实测结果**，工具可用性一律以本次实际探测为准。

## 来源分级（A1 / A / B / C / D / E）
| 级 | 类型 | 用途边界 |
|---|---|---|
| **A1** | **国家法律法规数据库 / 权威法律数据库（北大法宝等）** | **法条文本与现行有效性的最高权威源，优先使用** |
| A | 法律法规/行政法规/司法解释/官方判例 | 关键定性（可不可解除、是否违法解除）**必须 A 级** |
| B | 官方实施资料（人社部解释/办事指南/标准/地方高院会议纪要） | 解释落地，**不得改变上位法** |
| C | 公开专业参考（律所/劳法专家文章） | 仅线索，不单独支持停止/重大风险/放行 |
| D | 自媒体/二手转载（网络段子式经验如「孕期绝对不能解」） | 原则上不引用，仅用于发现检索关键词 |
| **E1** | **本技能实体层**（`dismissal-pathway.md` / `evidence-checklist.md` —— 基于经验与学习材料的总结） | 🔴 **不可支撑确定性结论**。仅作**检索线索**与**分析框架**；凡结论依赖其中法条表述，**必须回 A1 取原文** |
| E2 | 企业知识库（`user-knowledge/` 下的制度/SOP/历史结论） | 辅助定位，**不得推翻 A1/A 级权威源**；可抬高内控等级，不得降低法定风险 |

## 🔴 E1 自证循环禁令（本技能特有）

技能自己的经验总结**不构成对自身的证据**。禁止下列写法：

```
❌ 报告「依据」栏写：技能手册V4 / 解聘手册V4 / 实体层第40条三步法
✅ 报告「依据」栏写：《劳动合同法》第40条第2项（现行有效）
```

**E1 的正确用法**：作为**检索线索**（"第40条不能胜任"→去查原文）、作为**分析框架**（先排第42条→五步排除法）、作为**风险提示**（"这里容易踩坑"）、作为**证据清单模板**（帮HR自查）。

**E1 的错误用法**：当作依据、替代原文核验、用"手册说"说服用户。

> 完整机制见 `knowledge-integrity.md`。E1 文件带 `confidence` 与 `staleness-trigger` 元数据，命中触发条件即须重新核验。

## 同名多版本识别（强制）
司法解释存在「中文名相同、法效不同」的多版本（如解释(二)：法释〔2006〕6号已废止 / 法释〔2025〕12号现行）。
- 引用前必须核验三项：① 现行文号（法释〔年份〕号）② 施行日期 ③ 是否被新解释明文废止
- **仅凭中文名称不得引用**；引用必须写出文号与施行日期
- 同名多版本且无法确认 → 强制标【需专业人员确认】，不得单选其一

## 时效核验（防旧法，全场景强制）
1. 法条以官方现行有效版本为准（含生效日期、最新修正）。
2. 每次引用标注版本年份 + 效力状态。
3. 高频变动项（最低工资、社保基数、经济补偿免税额、地区口径）必须运行时重查，不沿用旧值。
4. 征求意见稿/草案不作现行依据，仅作趋势提示。
5. 时效无法确认 → 标「待核验」，不作确定性结论支撑。

## 检索纪律
- 官方来源优先；不以新闻报道替代原文。
- 法规检索与案例检索**分渠道**（法规走法律检索MCP；案例走官方案例库），详见 `kb-search-protocol.md`。
- 来源记录：名称/机关/发布日/生效日/效力/URL/检索日期；法规到条、案例记案号/法院/日期/要旨。
- 同一结论保留 ≤3 条最直接依据。
- 无法访问原文/仅摘要 → 标「待核验」；新旧冲突按衔接条款处理，不自行推定。
