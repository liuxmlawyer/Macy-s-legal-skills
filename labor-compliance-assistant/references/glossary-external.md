# 底稿术语 → 用户表达（HR/老板版）

把底稿结构化术语映射为 HR/老板可懂的自然表达。报告不出现工具名/内部编号/推理过程/连接器细节。

| 底稿术语 | 用户表达 |
|---|---|
| 第40条第2项不胜任解除 | 需要先有书面绩效考核 + 培训/调整岗位程序，否则可能构成违法解除 |
| 第43条通知工会 | 需先通知工会；工会未回复不得自行视为同意 |
| 送达程序 | 需留存送达证据，否则可能被认定未送达 |
| 证据缺口 | 证据是当前最大变量，先补齐考核/程序/送达记录 |
| 【禁止或重大风险】 | 有较高违法风险，建议先咨询法务/律师 |
| 【可整改风险】 | 有条件合规：补齐手续/证据/程序即可降低风险 |
| 【需专业人员确认】 | 需由法务/律师/当地仲裁确认后再行动 |

> 交付前扫描标题/小标题/正文，出现第二人称必须改写；不得诱导「直接辞」式建议。
