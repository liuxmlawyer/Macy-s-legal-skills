# 用工领域子域与触发信号

命中用工管理任一场景时，据此定位所涉领域子域。

| 子域 | 触发信号 | 核心定性关注 |
|---|---|---|
| 招聘录用 | 发布职位/面试/offer/背景调查/录用条件 | 招聘歧视、录用条件明确性、offer 法律效力 |
| 劳动合同订立 | 签合同/未签/合同期限/续签 | 书面合同义务、二倍工资、固定/无固定期限 |
| 劳动合同履行变更 | 调岗/降薪/工作地点/内容变更 | 协商一致、合理性、单方变更边界 |
| 试用期 | 试用期期限/录用条件/试用解除 | 试用期法定上限、录用条件、解除要件 |
| 绩效考核与不胜任 | 考核/末位淘汰/不胜任解除 | 考核制度效力、考核记录、不胜任程序 |
| 工时休假加班 | 工时制度/加班/带薪年休假/法定假 | 综合/不定时工时审批、加班费、年休假天数 |
| 薪酬社保公积金 | 工资/扣发/社保/公积金/经济补偿基数 | 按时足额、欠薪、社保缴纳、基数口径 |
| 特殊保护 | 三期/医疗期/工伤/婚丧产假 | 不得解除情形、待遇与保障 |
| 解除终止 | 解除/终止/协商/经济补偿/违法解除 | 法定情形、程序、通知工会、送达、赔偿 |
| 竞业保密 | 竞业限制/保密协议/离职后义务 | 竞业主体范围、期限、补偿、违约金 |
| 制度效力 | 规章制度/员工手册/民主程序/公示 | 民主程序、公示告知、效力的认定 |
| 用工形态 | 劳务派遣/非全日制/外包/实习 | 用工形态边界、同工同酬、连带责任 |

> 命中维度只是召回线索；结论需真实检索 + 时效核验，并经「相关性 + 方向 + 区分度」过滤后才进问题清单。
