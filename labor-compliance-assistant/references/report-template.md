# 报告模板（用工版）

## 报告结构

```
<用工事项> 用工法律合规评估报告 · <日期>

评估结论摘要（总体判断 / 主要风险 / 核心建议 / 用工所在地·日期·材料与政策包边界）
一、用工背景与评估范围
二、法律分析（按「（编号）主体关系：核心风险」组织）
三、待专业人员确认事项
四、整改建议
五、风险与建议汇总表
证据清单（可选，按需）
合规处理流程（可选，对接既有 SOP）
知识层核验状态（v3.0 新增，必填）
免责声明
尾注：来源与检索截止日期
```

二级标题采用「（编号）主体关系：核心风险」格式，如：
- （一）用人单位与劳动者：解除合法性核心风险
- （二）用人单位与工会：程序义务风险

编号在每个大节下从「（一）」重新起算。

---

## 文体与说理

- 标题、层级标题、表格字段**第三人称客观表述**；禁止对话式标题（「需关注事项」改为「主要风险」）。
- **全文不用第二人称**。交付前扫描，出现"你/你们"必须改写。
- 律师意见书式：直接切入，不预告步骤；给倾向 + 写明依赖的关键事实 + 事实翻转时的应对；连贯散文；收敛篇幅。
- 分析按**法律关系与具体问题**组织，**不得按子域名称平铺**。
- 每个法律问题写成连贯段落，把规则、事实、判断自然衔接；**不使用「规则/分析/结论/建议」标签分段**，不拆成大量并列圆点。

### 说理纪律（不树靶子、不自我辩驳）

| ❌ 不写 | ✅ 写法 |
|---|---|
| 「此处需先厘清 X、再判断 Y」 | 直接展开实质分析 |
| 「不宜径直认定为……」「不应简单理解为……」 | 直接就事实与法律给出判断 |
| 把两种可能并列摆着不表态 | 给倾向结论 + 写明依赖事实 + 翻转时的应对 |
| 为凑长度罗列法条、复述抽象标准 | 把抽象规则落到本案事实上 |

## 🔴 限定不可精简（精度禁区）

> 收敛篇幅只针对**冗余、铺陈、复述**，**不针对规则本身的准确度**。

凡转述带**期限、起算点、适用主体、合法性基础、比例或前提条件**的法律规则，
**必须连同这些限定一起转述**，不得为让句子变短而删掉限定、或把条件性规则写成绝对化结论。

**此项贯穿全文，含整改建议与汇总表。**

### 用工领域的典型禁区示例

| ❌ 错误写法 | ✅ 正确写法 |
|---|---|
| 医疗期内不得解除 | 医疗期内**不得依据第40条、第41条**解除；存在第39条法定过错的，仍可解除 |
| 三期女职工不能辞退 | 孕期、产期、哺乳期内**不得依据第40条、第41条**解除；协商解除（第36条）不受此限 |
| 提前30天通知即可解除 | 依据第40条单方解除的，应**提前30日书面通知**劳动者**或者**额外支付劳动者一个月工资 |
| 经济补偿封顶是3倍工资 | 月工资**高于本地区上年度职工月平均工资三倍**的，按三倍数额支付，**年限最高不超过十二年** |
| 竞业限制最多2年 | 竞业限制期限**不得超过二年**；且竞业限制人员**限于**高级管理人员、高级技术人员和其他负有保密义务的人员 |
| 加班费按规定支付 | 工作日延长工作时间支付**不低于150%**工资；休息日安排工作又不能安排补休的支付**不低于200%**；法定休假日支付**不低于300%** |
| 社保是员工自愿 | 参加社会保险是**法定强制义务**，员工放弃的条款无效 |

**用法条采用的标准表述**，不用日常模糊量级词替换（写"三倍"不写"好几倍"，写"三十日"不写"提前一些"）。

## 条号与来源露出

- 正文提炼规则要点，同一法条**首次出现**点条号 + 一句核心规则，后续直接援用不重复。
- **条号密度硬上限**：同一部法规在同一小节内，点出的具体条号 **≤3 个**；确有多条相关时列最核心 2–3 条，其余以「等」概括。**禁止把义务清单或罚则逐条搬进正文**。
- 处罚/赔偿只写**幅度定性**（如「可处罚款直至吊销许可」），不照抄数额区间与各档情形原文；具体数额由计算器给区间 + 标注待人工确认。
- **版本与效力**：引用法规时标注版本年份与效力状态（如「《劳动合同法》（2012年修正，2013年施行，现行有效）」），至少在该法规首次出现处和文末尾注标明。
- **链接**：正文**不内嵌 URL**，尤其不得用 `["https://..."]` 角标；出处一律收进**文末尾注**，同一法规只出现一次。
- 链接优先用官方稳定地址（flk.npc.gov.cn、最高法官网、地方人社局公告）；无稳定链接时只注明来源名称与检索日期。

### 🔴 依据栏禁令

报告「依据」栏**只能写**：法规名称 + 条号 + 文号 + 效力状态。

**禁止**出现：
- ❌「技能手册V4」「解聘手册V4」「实体层」「经验总结」
- ❌「企业内部惯例」（应写「依据企业《绩效考核制度》v2.0」并置于政策核对表，非法律依据栏）
- ❌「本技能认为」

## 章节要求

### 评估结论摘要

- 总体判断：可按当前方案推进 / 满足条件后可推进 / **不建议按当前方案推进** / 信息不足；
- 主要风险：按风险等级排序；
- 核心建议：列最关键的整改动作；
- 用工所在地、评估日期、材料边界与政策包使用情况。

### 一、用工背景与评估范围

用工形态、参与方、核心用工流程（招聘→订立→履行→变更→退出）、
适用地区、已确认事实 / 待确认事实 / 分析假设、本次评估包含与不包含的事项。

### 二、法律分析

每节顺序：
1. 点明该主体关系下的行为
2. 适用规则要点（带限定）
3. 结合本案事实的定性与风险等级
4. 事实不确定时的条件式翻转（「若……则……；若不……则……」）
5. 末尾另起一行「**依据：**」列出法条与案例

### 三、待专业人员确认事项

逐条写明：需要确认的问题 / 当前无法判断的原因 / 需补充的事实或资料 / 建议的专业领域与责任角色。

### 四、整改建议

每条一句可执行的话：**针对哪项风险 · 由哪个角色 · 在建议期限内 · 做什么具体动作 · 达到什么降险效果**。

避免「加强管理」「做好合规」这类无法执行的空泛表述。援引法律要求（保存期限、起算点、适用主体）时同样受**精度禁区**约束。

### 五、风险与建议汇总表

| 序号 | 法律问题 | 风险等级 | 事实缺口 | 核心依据 | 整改措施 | 责任角色 |
|---|---|---|---|---|---|---|

### 知识层核验状态（v3.0 新增 · 必填）

```markdown
### 知识层核验状态

- 本次引用知识层文件：dismissal-pathway.md（confidence: high，核验于 2026-10-14）
- 已回权威源核验的法条：第36/39/40/41/42/43/44-48条、劳动争议司法解释（二）
- **发现的差异**：1 处（见下）
- **未核验项**：地区口径（北京/上海/深圳/四川）需按用工所在地实时检索
- **结论可靠性**：本次确定性结论均建立在 A1 权威源之上，知识层仅作分析框架

#### 发现的差异（同步待办）

| 位置 | 知识层表述 | 权威源实际表述 | 处置 |
|---|---|---|---|
| §5.4 第一步 | 「三步法：培训→复考→解除」 | 第40条第2项：「经培训**或者**调整工作岗位」 | 以法条为准；建议修订知识层 |
```

**无差异时也须写明"本次未发现差异"**，不得省略该节。

### 免责声明

- 报告基于指定日期、用工所在地和现有材料生成；
- 事实变化或法律更新可能导致结论变化；
- 报告属于辅助研究，**不替代具备相应资格的律师正式意见**；
- 需专业人员确认的事项在确认前**不得作为确定性放行依据**。

### 尾注：来源

来源不占正文编号，统一置于文末尾注：

**A 级法律依据**（名称 / 机关 / 文号 / 施行日 / 效力状态 / 检索日期）
**官方口径与案例**（会议纪要 / 裁判指引 / 典型案例，标注地域与层级）
**公开专业参考**（律所文章 / 专家解读，标注"仅供参考"）
**企业政策包**（政策名称 / 版本 / 适用范围，**不暴露敏感资源地址**）
