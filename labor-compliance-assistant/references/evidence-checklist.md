# 证据清单（E1 经验层）

> **本文件是 E1 级经验归纳（清单模板 + 风险提示），不是法律依据。**
> 依据：《劳动用工—员工解聘手册（增强修订版 V4）》第2章「电子证据固定与保管指引」及各场景流程。
> 引用本清单时，涉及举证责任与程序义务的法条须回 A1 权威源核验，详见 `knowledge-integrity.md`。
> **举证责任原则**：依《劳动争议调解仲裁法》第6条及司法解释，**与争议事项有关的证据属于用人单位掌握管理的，用人单位应提供**；不提供的，承担不利后果。
> 这意味着——**企业缺少证据，等于承认员工主张**。

---

## 零、证据的三性要求

| 特性 | 含义 | 不满足的后果 |
|---|---|---|
| **真实性** | 客观存在且未被篡改 | 真实性存疑 → 不予采信 |
| **合法性** | 收集手段合法（不得偷拍、窃听、暴力取证） | 违法取证 → 排除或不利认定 |
| **关联性** | 与待证事实有逻辑关联 | 无关证据 → 排除 |

---

## 一、制度效力证据（依赖规章制度解除时**必备**）

**没有这一段，第39条第2项「严重违反规章制度」解除直接不成立。**

| # | 证据 | 证明什么 | 缺失后果 | 收集责任人 |
|---|---|---|---|---|
| 1.1 | 员工手册/规章制度**全文** | 规则内容 | 无法指明违反了哪一条 | HR |
| 1.2 | **职工代表大会决议**（或全体职工讨论记录） | 制度经民主程序制定 | 🔴 **制度不能作为解除依据** | HR/工会 |
| 1.3 | 与工会/职工**平等协商**的证据 | 协商程序合法 | 🔴 民主程序瑕疵 | HR |
| 1.4 | **公示证据**：公告栏照片+张贴日期、员工手册签收表、系统推送记录、培训签到 | 员工已知悉 | 🔴 未公示 → 制度对其不生效 | HR |
| 1.5 | 制度**修订历史**（版本号+生效日期） | 解除时适用的是有效版本 | 适用了已废止版本 | HR |
| 1.6 | 工会**建立情况**说明 | 是否需通知工会 | 漏通知工会 → 程序违法 | HR |

## 二、事实认定证据（证明"员工做了什么"）

### 2.1 绩效考核类（不胜任解除的核心）

| # | 证据 | 证明什么 | 缺失后果 | 责任人 |
|---|---|---|---|---|
| 2.1.1 | **岗位说明书/岗位职责** | 该岗位的客观要求 | 无标准 → 无法认定"不能胜任" | HR |
| 2.1.2 | 考核**标准**（量化指标，非"德才兼备"式表述） | 考核的合理性 | 标准模糊 → 考核结果不被采信 | HR/绩效 |
| 2.1.3 | 考核**原始记录**（含事实依据：数据、邮件、交付物） | 不胜任的**客观依据** | 🔴 仅上级主观打分 → 举证不能 | 直线主管 |
| 2.1.4 | 考核结果**送达证据** | 员工知悉 | 未送达 → 考核未生效 | HR |
| 2.1.5 | 员工**申诉记录**及企业答复 | 保障程序性权利 | 未给申诉机会 → 法院认定程序瑕疵 | HR |
| 2.1.6 | **历次考核结果**（不只最后一次） | 是否一贯不胜任 | 单次考核不足以证明 | HR |

### 2.2 违纪行为类（第39条第2项）

| # | 证据 | 证明什么 | 缺失后果 |
|---|---|---|---|
| 2.2.1 | 违纪行为的**客观载体**（聊天记录、邮件、监控、考勤） | 行为事实 | 无载体 → 主张不成立 |
| 2.2.2 | **时间线证据**（事发、发现、调查全过程） | 行为的时间与过程 | 时间线不清 → 无法与制度条款对应 |
| 2.2.3 | 企业**调查记录**（谁调查、问谁、员工是否陈述） | 调查程序的正当性 | 未调查直接认定 → 程序瑕疵 |
| 2.2.4 | 员工**申辩记录** | 已给予申辩机会 | 未申辩机会 → 可能认定程序违法 |
| 2.2.5 | 制度中**违纪分级/解除情形条款** | 该行为是否达到"严重" | 无法对应"严重违反" |
| 2.2.6 | 同类行为的**既往处理先例**（从轻/从重） | 处理一致性 | 差别待遇 → 违反平等原则 |

### 2.3 电子证据专项（互联网企业/远程办公）

| # | 证据类型 | 固定方法 | 证明力 |
|---|---|---|---|
| 2.3.1 | 企业微信/钉钉/飞书聊天 | **系统导出+时间戳** | 高（需原始载体） |
| 2.3.2 | 邮件 | 保留**完整邮件头**（含服务器时间） | 高 |
| 2.3.3 | 考勤/打卡系统数据 | 系统后台导出+操作日志 | 中高（需防篡改说明） |
| 2.3.4 | OA/审批流记录 | 系统导出，带流程编号 | 高 |
| 2.3.5 | 代码提交/工单系统（研发岗） | Git log / Jira 记录 | 高（客观且不可篡改） |
| 2.3.6 | 监控/门禁录像 | 保留原视频+录像时间说明 | 中（需说明未被剪辑） |
| 2.3.7 | 微信群聊（客户/员工） | **手机截图不足** → 需公证或第三方存证 | ⚠️ 截图证明力低 |

> ⚠️ **电子证据三大误区**：
> 1. **只截图不保全原件**——对方可否认，法庭倾向采纳原始载体
> 2. **删除后取证**——涉嫌违法，需说明取证时间与方式
> 3. **用工系统数据无操作日志**——容易被质疑可事后修改

## 三、程序履行证据（第40/41条必备）

| # | 证据 | 证明什么 | 缺失后果 |
|---|---|---|---|
| 3.1 | **培训计划**（针对具体不胜任项） | 培训有针对性 | 🔴 泛泛培训无效 → 视为未培训 |
| 3.2 | 培训**通知**+员工签收 | 已告知培训 | 员工否认参加 |
| 3.3 | 培训**签到表/考勤** | 实际参加 | 无签到 → 无法证明履行 |
| 3.4 | 培训**材料/课件** | 培训内容具体 | 泛泛培训 → 前置程序形同虚设 |
| 3.5 | 培训后**考核结果** | 培训效果 | 未考核 → 无法进入下一步 |
| 3.6 | **调岗通知书**（若走调岗） | 已履行调岗程序 | 🔴 未调岗直接解除 → 违法 |
| 3.7 | **新岗位说明书** | 调岗有明确岗位 | 岗位不清 → 调岗无效 |
| 3.8 | 调岗**合理性说明**（薪资、地点、职责变化及理由） | 调岗非变相辞退 | 合理性存疑 → 调岗被否 |
| 3.9 | 调岗后**新的考核周期记录** | 重新考核 | 🔴 沿用调岗前记录 → 程序违法 |
| 3.10 | 经济性裁员：**提前30日说明**记录 | 已履行告知义务 | 🔴 未告知 → 裁员违法 |
| 3.11 | **听取意见记录**（工会/职工意见及答复） | 已听取意见 | 未听取 → 程序瑕疵 |
| 3.12 | 向劳动行政部门**报告**的凭证 | 裁员程序完成 | 未报告 → 程序违法 |
| 3.13 | **协商解除全过程沟通记录**（走第36条时） | 系双方协商而非单方通知或胁迫 | 🔴 无记录 → 事后易被主张为变相逼退 |
| 3.14 | 协商解除协议**员工本人签字原件** | 员工真实意思表示 | 代签/无签字 → 协议效力存疑 |
| 3.15 | **产假工资/生育津贴结算凭证**（三期员工） | 相关待遇已依法结清 | 🔴 未结清 → 员工可主张公司未足额支付 |

> 📌 **3.13–3.15 适用于三期员工等无第39条过错证据、拟走第36条协商解除的情形。**
> 第42条限制第40、41条，但**不限制第36条**；在无第39条法定过错的场景下，
> 协商解除是风险最低的通道。
> 协商解除的全部合法性都落在"确实是双方自愿协商"这一点上，
> 因此沟通记录与本人签字是**最关键**的护身符。
> （若另有第39条法定过错证据，则应另行评估第39条路径，本段不适用。）
> 🔴 特别提醒：协议中**不得写"员工自愿离职"**——若实际由公司主导谈判，
> 该表述可能被推翻，公司仍须承担 2N。

## 四、特殊保护排查证据（第42条阻断）

**这一段是"防守证据"——用来证明企业已排除不得解除情形，避免程序违法。**

| # | 证据 | 证明什么 | 缺失后果 |
|---|---|---|---|
| 4.1 | 员工**花名册**（含入职日期、工龄计算依据） | 工龄、是否"15年+5年" | 工龄算错 → 补偿金差额 |
| 4.2 | 员工**三期待遇情况书面声明**（入职时或定期） | 是否孕期/产期/哺乳期 | 🔴 三期违法解除 |
| 4.3 | 员工**社保缴纳记录** | 是否已到退休年龄可领养老金 | 误判为三期 |
| 4.4 | 工伤认定书 + **劳动能力鉴定结论** | 是否丧失/部分丧失劳动能力 | 工伤员工违法解除 |
| 4.5 | **职业健康检查**记录（涉职业病危害岗位） | 解除前已履行检查义务 | 🔴 未检查 → 劳动者可请求继续履行 |
| 4.6 | 员工**退休年龄相关证明**（档案年龄/身份证） | 是否距退休不足5年 | 年龄争议 |
| 4.7 | 工会干部/职工代表**身份确认** | 是否属特殊身份需保护 | 漏通知工会 |
| 4.8 | 三期员工的**产假申请单/产检记录** | 孕期与产假的具体时点 | 🔴 时点不明 → 无法判断第42条、第45条的适用期间 |
| 4.9 | 三期员工的**劳动合同原件**（含起止日期） | 合同何时到期、是否将遇第42条情形 | 🔴 **误以为"合同到期就能终止"**——第45条强制顺延，妇女权益保障法第48条第2款产假期间自动延续 |
| 4.10 | **协商解除协议**（若走第36条） | 双方协商一致的意思表示 | 🔴 缺失 → 无法证明是协商而非单方解除 |

> 📌 **实操建议**：入职时建立"特殊保护情形告知表"，员工签字确认，既尽管理义务又形成证据。

> 🔴 **三期员工特别提示（2026-10-14 实战补充）**：
> 三期员工一旦出现"不想返岗"的意向，**公司按第40、41条解除的路径被第42条第4项阻断**，
> 第45条亦阻断"合同到期"路径；在**没有第39条法定过错证据**的常见情形下，
> 优先评估**第36条协商解除**，其全部合法性落在
> **4.10 + §三的 3.13/3.14/3.15** 这几项证据上。
> **证据不足 = 协议可能被推翻 = 公司仍须承担 2N。**
> （若已存在第39条法定过错证据，应另行评估第39条路径及其证据要求。）
> 详见 `dismissal-pathway.md` §5.8.1 三期女职工专项。

## 五、薪酬与送达证据

### 5.1 工资结构证据（决定补偿基数）

| # | 证据 | 证明什么 |
|---|---|---|
| 5.1.1 | 劳动合同**约定的工资** | 约定工资 |
| 5.1.2 | 解除前**12个月工资明细**（工资条/银行流水） | N 和 +1 的计算基数 |
| 5.1.3 | **奖金/提成/津贴**发放记录 | 是否计入月工资 |
| 5.1.4 | 当地上年度**职工月平均工资**（3倍封顶用） | 封顶基数 |
| 5.1.5 | 加班费/特殊津贴构成说明 | 是否应计入月工资 |

### 5.2 送达证据（最易被忽略，直接决定解除是否生效）

| # | 证据 | 证明什么 | 缺失后果 |
|---|---|---|---|
| 5.2.1 | **EMS快递单**（含面单截图） | 已寄送 | 未送达 → 解除未生效 |
| 5.2.2 | **签收记录**（本人签收/代收人/拒收） | 通知已到达 | 🔴 无签收 → 可能认定未通知 |
| 5.2.3 | 员工**送达地址确认书**（入职时填写） | 送达地址真实有效 | 寄错地址 → 未送达 |
| 5.2.4 | 电子送达**授权书**（如约定邮件送达） | 电子送达有效 | 无授权 → 电子送达无效 |
| 5.2.5 | 公告送达的**公告文本+公告张贴照片** | 间接送达 | 需满足"确实无法送达"前提 |
| 5.2.6 | 送达**全过程说明**（多渠道组合） | 穷尽送达努力 | 单一渠道失败即放弃 → 程序瑕疵 |

> 🔴 **送达是解除的最后一米**。通知书写再好，送不到等于没做。

## 六、按解除路径的证据组合速查

| 解除路径 | 必备证据段 | 最易缺的一段 |
|---|---|---|
| 协商解除 | 协议+工资结算 | 奖金/提成结算条款 |
| 试用期不符合录用条件 | 录用条件告知+考核 | **录用条件的事前告知** |
| 严重违反规章制度 | 制度效力+违纪事实+调查 | **民主程序+公示** |
| 不能胜任工作 | 制度效力+考核+培训/调岗+复考 | **培训针对性证明** |
| 客观情况重大变化 | 客观情况证据+协商记录 | 协商未果的证明 |
| 经济性裁员 | 42条排查+30日告知+意见+报告 | **向劳动行政部门报告** |
| 合同期满终止 | 续订通知+到期证明 | 二次到期终止权风险评估 |
| 医疗期满解除 | 医疗期证明+劳动能力鉴定 | **先调岗要求**（部分地区） |

## 七、证据保管要求

| 要求 | 说明 |
|---|---|
| **期限** | 劳动关系终止后**至少2年**（《劳动争议调解仲裁法》第27条仲裁时效1年，建议2年） |
| 载体 | 电子证据须**原始载体 + 副本**，注明取证时间与方式 |
| 备份 | 重要证据双备份（云端+本地），防篡改 |
| 脱敏 | 涉及员工个人信息，报告与外发材料须**脱敏** |
| 跨客户 | 企业间证据与材料**不复用** |
