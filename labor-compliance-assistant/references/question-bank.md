# 澄清提问（HR/老板版）

## 原则
- 只问会改变适用法律/主体定性/结论/风险等级的问题；优先问事实不问法律结论。
- **一轮聚焦 1–4 问**，提供「不确定」出口。
- 语态面向非法律人，不用法条编号吓人。
- 技术/合同事实由实际负责人确认。

## 用工场景必问关键事实
1. **工龄与入职时间**：入职多久？合同类型（固定/无固定/项目）？
2. **工资结构**：月工资构成（基本工资/绩效/奖金）？是否含加班费？
3. **证据情况**：有无书面绩效考核制度与考核记录？有无 PIP/培训/调整岗位记录？送达记录？
4. **特殊情形**：是否三期、医疗期、工伤、孕产哺？是否属于「不得解除」情形？
5. **所在城市**：公司注册地 / 用工所在地？（地区口径差异）
6. **程序要件**：是否设立工会？是否经民主程序的规章制度？是否已履行协商/通知程序？

> 只问会改变定性/风险等级的问题；「不确定」时按双通道检索 + 待专业人员确认处理，不臆断。
