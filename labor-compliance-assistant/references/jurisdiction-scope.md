# 地区口径与冲突处理

> 劳动法的最大不确定性来源是**地区差异**。
> 本文件解决一个问题：**这个结论是"全国统一规则"，还是"我们这个城市另有口径"？**

---

## 一、默认适用范围

- **中国大陆**劳动用工领域；
- 效力范围：**全国性法律、行政法规、部门规章、司法解释**在全国统一适用；
- **地方口径**（地方高院会议纪要、裁判指引、地方规定）**只在本地有实质影响**；
- 本技能**不提供**境外劳动法分析。涉及港澳台、涉外用工、境外派驻时，直接说明超出范围并建议咨询当地执业律师。

---

## 二、法域识别（评估前必须确认）

至少确认以下四项，写入底稿：

1. **用人单位主体所在地**（营业执照注册地）
2. **实际用工所在地**（员工实际工作地点）
3. **劳动合同履行地**（合同约定或实际履行地）
4. **劳动合同签订地**

### 冲突时的适用：按争议类型与具体规范分别判断

**不存在"实际用工所在地 ＞ 劳动合同履行地 ＞ 签订地 ＞ 注册地"的通用排序。**
适用规则随**争议类型**与**所依据的具体规范**而变，必须分别检索确认：

| 争点类型 | 依据与判断方式 |
|---|---|
| **实体标准**（最低工资标准、劳动保护、劳动条件、职业危害防护、本地区上年度职工月平均工资等） | 《劳动合同法实施条例》（国务院令第535号，2008-09-18公布施行）**第14条**：劳动合同履行地与用人单位注册地不一致的，上述事项按**劳动合同履行地**的有关规定执行；**但用人单位注册地的有关标准高于劳动合同履行地的有关标准，且用人单位与劳动者约定按照注册地的有关规定执行的，从其约定**。→ 即"履行地优先"**存在明确例外**，不得用固定排序否定该约定 |
| **程序管辖**（劳动争议仲裁由哪一地受理） | 依《劳动争议调解仲裁法》第21条等规定单独判断：一般由劳动合同履行地或用人单位所在地仲裁委员会管辖；两地不一致时由劳动合同履行地管辖。**这与实体标准适用地不是同一问题**，不得混为一谈 |
| **地方裁判口径**（末位淘汰、二次到期终止权、调岗合理性标准等） | 按**用工所在地**的地方高院会议纪要、裁判指引等分别检索；不同地区的差异只能按地区分别适用，不存在跨地区通用的排序 |
| **社保征缴与补缴** | 按参保地社保经办机构口径与实际参保事实判断；**地方是否存在允许现金折抵的做法，须检索该地具体规范后方可提示**，不得预设 |

> ⚠️ **不得用一个"优先顺序"回答所有问题**：实体标准、程序管辖、地方口径、
> 社保征缴各自有独立的判断路径，须分别给出结论与依据。

**事实不清时**：把实际用工所在地、劳动合同履行地、注册地、签订地分别列为**待确认事项**，
不臆断；并在报告中写明每一项结论是按哪个争点类型、依据哪一条具体规范作出的。

## 三、多地用工情形

### 3.1 分散用工（多地各有员工）

- **分别适用**各地口径，**不套用统一口径**；
- 集团制度可能需按地分别修订（如工时制度在各地审批要求不同）；
- 跨地区调动 → 可能涉及**劳动合同履行地变更**与**协商一致**问题。

### 3.2 远程/混合用工

| 情形 | 注意事项 |
|---|---|
| 员工远程办公，雇主所在地与工作地分离 | 适用法域可能取决于**合同约定+实际管理地** |
| 在家办公期间发生工伤 | 认定地可能不同于单位所在地 |
| 跨省社保缴纳 | 需分别处理社保转移与两地缴纳合规问题 |

→ 事实不清时**标【需专业人员确认】**，不做单一结论。

### 3.3 劳务派遣

- **用工所在地**通常指**派遣用工所在地的用工单位所在地**；
- 派遣单位所在地与用工单位所在地口径可能不同，需分别确认。

## 四、地区口径检索方法

### 4.1 检索词模板

```
"{城市} 劳动争议 裁判指引 第X条"        → 地方高院/中院裁判指引
"{城市} 中院 劳动争议 审理指引"          → 系统性地区口径文件
"{城市} {争议点关键词} 裁判标准"         → 针对具体争点
"{城市} 劳动争议 典型案例 {年份}"        → 本地案例
"{城市} 人社局 答复 解除 赔偿"           → 地方行政口径
"{城市} 上年度 职工月平均工资 公布"      → 3倍封顶基数（人社局/统计局）
```

### 4.2 常见地区口径文件类型

| 类型 | 示例形式 | 本技能分级 | 效力说明 |
|---|---|---|---|
| 会议纪要 | 《XX省高院劳动争议审判会议纪要》 | **B** | 非法律渊源，但实践影响大 |
| 裁判指引 | 《XX市中院劳动争议裁判指引》 | **B** | 地方审判参考 |
| 答复/意见 | 人社部门或高院答复 | **B** | 行政或审判参考 |
| 典型案例 | 法院发布的本地典型案例 | **C** | 个案约束力 |
| 地方规定 | 《XX市最低工资标准》 | **A/B** | 强制性地方规范，须查现行版本 |

> ⚠️ 会议纪要与裁判指引**不属于法律渊源**，**不得改变上位法**，但**地方法院实际参照执行**。报告中须标明地域与文件性质。

## 五、高频地区争点清单（须按当地核验）

| 争点 | 常见分歧 |
|---|---|
| **末位淘汰 = 不胜任？** | 深圳、四川明确不支持；部分地区口径不一 |
| **二次到期终止权** | 北京、上海有明确口径 |
| **代通知金基数** | 上海、深圳有专门口径 |
| **经济补偿封顶基数** | 部分地区执行细则不同 |
| **经济性裁员程序** | 各地对报告程序的宽严不同 |
| **严重违纪的"严重"标准** | 需看当地对违纪分级的认定尺度 |
| **调岗合理性标准** | 北京、四川等有专门口径 |
| **社保补缴抗辩** | 各地征缴与补缴口径不一；**"现金补偿能否折抵社保"须检索该地具体规范后方可提示**，且现金补贴**不能免除法定参保义务**（法释〔2025〕12号第19条：约定或承诺无需缴纳社保的无效） |

> ⚠️ **不得跨地区套用口径**。
> 知识层（`dismissal-pathway.md` §八）的地区表**仅为提示框架**，具体口径**必须实时检索核验**，不得直接照用。
> 也不得用"某地有口径"推出"另一地没有"或"全国都可如此"。

## 六、冲突处理规则

### 6.1 地区口径与法律冲突

```
法律/司法解释（全国统一）
        ↓ 冲突
地方会议纪要/裁判指引
        ↓
结论：以法律为准，地方口径仅作实践参考
```

- 报告中**同时呈现**两者，说明差异；
- 地方口径实践影响大但效力低 → 提示用户**做好当地诉讼预期管理**；
- **不得**用地方口径推翻上位法。

### 6.2 各地口径互相冲突

- 分别分析，不用其中一个覆盖另一个；
- 报告中标明"本结论在A市成立，在B市可能有不同结果"；
- 建议**按最谨慎口径设计制度**，或分别修订。

### 6.3 口径查不到

- 明确告知"**未检索到该地区明确口径**"；
- **严禁编造**地方规定；
- 按全国统一规则给出结论，同时标注"**当地口径待确认**"；
- 进入待专业人员确认清单。

## 七、报告披露要求

每份涉及具体地区的报告**必须写明**：

- 已评估地区：**用工所在地城市**；
- 未覆盖地区：（如多地用工中未分析的其他城市）；
- 检索截止日期；
- 当地口径文件的名称、文号、层级（法律/纪要/指引/案例）；
- **建议取得当地法律意见的事项**。

---

## 八、边界

- 本技能**不替代**当地执业律师的地方口径判断；
- 地方高院会议纪要**可能未被公开检索到**（部分仅内部流转），此时**明确告知未检索到**，不推测其内容；
- 地区口径**变化快于法律本身**，任何地区结论都应标注**检索日期**。
