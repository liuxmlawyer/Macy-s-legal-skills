# 劳动法律问题构建与过滤

## 三步构建用工法律问题

1. **确定关系与法律地位**：双方是否成立劳动关系 / 何类用工形态 / 是否三期·医疗期·工伤等特殊保护 / 是否有工会 / 是否符合法定解除或终止情形。地位有争议标【需专业人员确认】。
2. **展开具体义务与程序**：从法律地位展开法定程序义务（第39/40/41/42条、第43条通知工会、送达、解除/终止证明、档案与社保办理），问题须能拆构成要件（如「是否已履行绩效考核并进入不胜任程序」）。
3. **过滤入选**（内部进行，滤除的不写入报告）：
   - **相关性**：直接指向该用工决策本身。
   - **成立性与方向**：处于「可能违法解除 / 可能违反程序」位置才立项。
   - **区分度（普适义务降级）**：面向本用工具体行为，而非任何企业都负担的普适底线（场景泛化勿立项）。

## 依赖标记与不确定性传播

- 依赖类型：前提到派生（先检前提，未定时条件分析）/ 并列（可同时检索）/ 独立。
- 前提未定（是否签合同、是否送达、是否民主程序、地区口径存疑）**不选有利分支**，各定性 + 义务写清 + 缺什么事实 + 需谁确认。
- 方向存疑但后果重大（如激进解除）→ 保留问题并标需补事实，不直接删除。
