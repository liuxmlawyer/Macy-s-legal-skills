# 用工排查维度（9 维）

逐项标「已明确 / 待确认 / 不适用」。命中维度是召回线索，须过「相关性 + 方向 + 区分度」内部判断。

1. **主体与用工形态**：劳动关系/劳务/派遣/外包；是否与法律主体直接关联。
2. **合同订立与效力**：书面合同、合同期限、试用期约定、特种合同。
3. **制度效力**：规章制度是否经民主程序 + 公示告知。
4. **工时与考勤**：工时制度、加班认定、加班费。
5. **薪酬社保**：按时足额、社保公积金、经济补偿基数。
6. **特殊保护**：三期、医疗期、工伤、未成年工/高龄、婚丧假。
7. **解除终止**：法定情形、程序、通知工会、送达、补偿/赔偿。
8. **衍生义务**：竞业限制、保密、离职后义务、档案/离职证明办理。
9. **清单外风险**（最后必查）：新型用工/复合风险（算法考核解除、社保挂靠等）。

> 落选的问题不写入报告。
