# 风险定级（三档）

| 等级 | 用工场景示例 | 要求 |
|---|---|---|
| **【禁止或重大风险】** | 违法解除、克扣工资、三期违法解除、未缴纳社保 | 必须提供直接法律依据（A 级），说明要件/事实/整改条件 |
| **【可整改风险】** | 手续缺口、证据不足、送达不规范 | 说明缺口、整改动作、剩余风险、责任角色 |
| **【需专业人员确认】** | 地区口径争议、制度效力存疑、集体/重大情形、关键事实缺失 | 写明不确定原因、所需事实、建议角色（法务/律师/仲裁） |

## 定级铁律（不可裁剪）
- 确定性结论必须有可核验依据。
- 仅网络摘要/非官方不直接定重大风险或放行。
- **个人库可抬高内控等级，不得降低法定风险**。
- 不得承诺「零风险 / 一定合法」。
- 法律风险等级与业务关注优先级分开记录，不混淆。

## 适用示例（劳动标准）
- 解除：第39条过错解除 / 第40条无过错解除（不胜任、医疗期满、客观重大变化）/ 第41条经济性裁员 / 第42条不得解除排除 / 第43条通知工会 / 第46-48条经济补偿与违法解除赔偿。
- 证据依赖判断（如不胜任）时，明确提示「证据缺口是当前最大变量」。
