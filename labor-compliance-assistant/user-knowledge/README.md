# 企业用工政策包（可选 · 授权加载）

> 本目录用于放置**企业自有**的用工政策材料：规章制度、解聘手册、内部 SOP、
> 审批流程、历史同类案件处理结论、风险偏好等。
>
> 🔴 **仅在用户显式指定并授权后加载。未授权时不读取、不推测。**

---

## 一、信任层级定位

本目录属 **E2 级**（企业知识库），与技能自带的 E1 经验层**同级**：

| 层级 | 内容 | 能否支撑确定性结论 |
|---|---|---|
| A1 | 权威源法条原文 | ✅ 可以 |
| E1 | 技能自带经验总结（`references/dismissal-pathway.md` 等） | ❌ 不可以 |
| **E2** | **本政策包** | ❌ **不可以** |

**E2 的正确用法**：了解企业内部要求、抬高内控等级、生成可执行步骤。
**E2 的错误用法**：当作法律依据、替代法条核验、放宽法定程序。

## 三、加载与优先级规则

| 情形 | 处理 |
|---|---|
| 政策包命中且内容可核 | **优先采用为「内部口径」**，报告中标注为企业要求 |
| 政策包缺失某项 | 回退公开法律依据，**不推测企业内部是否有规定** |
| 政策包内容模糊/版本不明 | 标【需核验】，按公开法处理 |

**优先级铁律**：

```
法律强制性要求  ＞  企业政策  ＞  风险偏好  ＞  操作建议
```

- 企业政策**可以抬高内控等级**（要求更严、程序更多）；
- 企业政策**不得降低法定风险**（不得放宽强制性程序、不得放弃法定权利）。

## 五、内容分类与可用性

| 类型 | 存放位置 | 能否用于结论 | 使用方式 |
|---|---|---|---|
| **已批准的强制制度** | `policies/` | 可作为**企业内部要求** | 不替代法律依据 |
| **已批准的风险偏好** | `risk-appetite/` | 可影响是否升级处置 | **不得放宽法律要求** |
| **操作流程和模板** | `procedures/` | 用于生成整改步骤 | 核验版本与适用范围 |
| **责任分工** | `routing/` | 用于指派责任角色 | 不替代法定程序 |
| **历史评估/个案结论** | 任意 | 仅作事实与检索线索 | **不自动视为现行口径** |
| **未确认反馈** | 任意 | ❌ 不得作为正式政策 | 进入待确认事项 |

> ⚠️ **历史个案不得自动升级为正式政策**。一次成功的谈判不等于下次可以照搬。

## 六、冲突处理

| 冲突类型 | 处理 |
|---|---|
| **法律 > 政策** | 以法律为准，提示用户**修订政策** |
| **政策 > 法律** | 可按政策给出建议，但必须明确标注"**严于法律最低要求**" |
| **政策内部冲突** | 标记【需专业人员确认】，请用户澄清适用范围 |
| **政策版本不明** | 按【待核验】处理，不猜测 |
| **公开实践 ≠ 政策** | 分别呈现，**不用公开文章推翻正式政策** |

**报告中的呈现方式**：

在「政策核对表」中单独成表，**不与法律依据混列**：

| 政策要求 | 法律最低要求 | 差异 | 处置 |
|---|---|---|---|
| 解除需提前45日通知 | 第40条：提前30日或支付代通知金 | 企业更严 | 按企业政策执行（严于法定） |
| 违纪两次即解除 | 法律未规定次数，需个案判断 | 企业设标准 | **需审查该标准是否合理** |

## 七、安全规则

1. **只有用户主动提供或授权连接器时**才加载；
2. 只读取与当前问题相关的**最小范围**，不整包吞入；
3. **不将内容复制回本技能**，不跨客户/跨企业复用；
4. 报告引用政策时**只记名称、版本、适用范围**，敏感链接不写入可外发报告；
5. 政策含个人信息、商业秘密时，**先最小化与脱敏**；
6. 无权限时**不主动申请**，不推测内容，**不把"未读取"解释为"不存在政策"**；
7. 政策包本身可能包含**过时的制度**（如已废止的规章制度版本），加载后应检查**是否仍现行有效**。

---

## 八、加载后的额外检查

加载政策包后，在底稿中确认：

- [ ] 政策包的**生效版本**是否仍为最新（有无更新版本未替换）
- [ ] 涉及解除的制度是否经**民主程序**且有**公示证据**
- [ ] 政策中设定的**违纪分级标准**是否存在、是否可操作
- [ ] 政策与法律的**差异点**是否已识别
- [ ] 是否有**已废止文件**残留

> 📌 **企业制度未经民主程序或未公示，可能整体不可作为解除依据**——
> 这本身就是评估中最常见的重大风险点之一，务必核查。
